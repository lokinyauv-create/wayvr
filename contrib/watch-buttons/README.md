# Watch buttons / Свої кнопки на годиннику

> **⚠️ Created with AI:** generated by AI — Claude (Anthropic) — at Lokinya's request, tested in VR.
> **Створено ШІ** (Claude, Anthropic) на прохання Lokinya, перевірено у VR.

Lokinya's build of WayVR shows a button on the watch for every `*.json` file in
`~/.config/wayvr/watch-buttons/`. Any program can add its own button this way.
Order and visibility: dashboard → «Кнопки годинника».

Збірка WayVR від Lokinya показує на годиннику кнопку для кожного файлу `*.json` у
`~/.config/wayvr/watch-buttons/`. Так свою кнопку може додати будь-яка програма.
Порядок і показ: панель налаштувань → «Кнопки годинника».

```json
{
  "name": "Discord",
  "tooltip": "Mute my mic in Discord",
  "icon": "discord-mute.svg",
  "press": "./discord-mute.py toggle",
  "active": "./discord-mute.py is-muted",
  "interval_ms": 1500
}
```

| field | meaning |
|---|---|
| `name` | short text under the icon / підпис під іконкою |
| `tooltip` | hint on hover / підказка |
| `icon` | SVG file, optional / іконка SVG (необов'язково) |
| `press` | shell command run on a click / команда на натискання |
| `active` | polled command: exit code 0 lights the button up / код 0 — кнопка світиться |
| `interval_ms` | how often `active` runs (default 1000) / як часто перевіряти |

Commands run with `sh -c` inside this folder. Keep `active` cheap: it runs all the time.

Install the examples: `curl -fsSL https://raw.githubusercontent.com/lokinyauv-create/wayvr/lokinya-build/get.sh | bash -s -- --buttons`

## Discord mute (`discord-mute.*`)

Mutes your mic **in Discord itself**: the mic is crossed out and everyone sees it.
It uses Discord's local RPC, so it needs your own (free) Discord application once:

1. Open <https://discord.com/developers/applications> → **New Application** → any name → **Create**.
2. **OAuth2**: turn on **Public Client**, add the redirect `http://localhost`, **Save**.
3. Run `~/.config/wayvr/watch-buttons/discord-mute.py setup`, paste the **Client ID**, press Enter
   (no secret needed), then click **Authorize** in Discord.

A small helper keeps one connection to Discord and follows its mute state, so the watch
never floods Discord with requests. The same command works for any hotkey or mouse button:
`discord-mute.py toggle`.

**Українською:** кнопка вимикає мікрофон **у самому Discord** (усі бачать перекреслений
мікрофон). Один раз: створи застосунок на <https://discord.com/developers/applications>
(New Application → Create), в OAuth2 увімкни **Public Client**, додай redirect
`http://localhost`, збережи. Потім запусти `discord-mute.py setup`, встав Client ID і натисни
в Discord «Авторизувати». Ту саму команду `discord-mute.py toggle` можна повісити на кнопку
миші чи клавішу.
